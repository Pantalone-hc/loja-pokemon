# Toca do Treinador

Site de uma loja de cartas Pokémon feito com Gatsby para a disciplina de Front-end Jamstack.

Site: https://pantalone-hc.github.io/loja-pokemon/

## Como rodar

npm install
npm run develop

As cartas ficam em `content/cartas`, cada uma com um arquivo `.md` e uma imagem.

O deploy é feito pelo GitHub Actions a cada push na branch `main`.
